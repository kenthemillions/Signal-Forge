================================================================================
DEPLOYMENT GUIDE: GitHub & Render.com
================================================================================

This guide will walk you through deploying your web application globally
using GitHub (for code hosting) and Render (for live hosting).

--------------------------------------------------------------------------------
STEP 1: GitHub Setup (Storing your code)
--------------------------------------------------------------------------------
1. Log in to your GitHub account (https://github.com).
2. Create a NEW Repository:
   - Click the (+) icon in the top right -> New repository.
   - Give it a name (e.g., "signal-forge").
   - Choose "Private" if you want to keep your code secret.
   - Click "Create repository".

3. Initial Setup (First Time Upload):
   - Click the "Source Control" icon on the left sidebar (looks like a branch).
   - If you see a "Initialize Repository" button, click it.
   - In the "Message" box, type "First commit" and press Enter.
   - Click the "Publish Branch" button.
   - Select "Publish to GitHub private repository" or "Publish to GitHub public repository".
   - Select the repository name you created in Step 1.2 from the list.

4. Pushing Updates (Afterwards):
   - Whenever you make changes, click the "Source Control" icon.
   - You will see your changed files under "Changes".
   - Type a short description in the "Message" box (e.g., "Updated UI").
   - Press Enter or click the checkmark icon to "Commit".
   - Click "Sync Changes" to push the updates to the cloud. Render will 
     automatically detect these changes and update your live site.

--------------------------------------------------------------------------------
STEP 2: Render.com Setup (Live hosting)
--------------------------------------------------------------------------------
1. Log in to Render (https://render.com). You can sign in using your GitHub account.
2. Connect GitHub to Render:
   - Click the "New" (+) button in the top right.
   - Select "Blueprint".
   - Connect your GitHub account if you haven't yet.
   - Select the repository you created in Step 1.
3. Deploy the App:
   - Give your blueprint a name (e.g., "live-app").
   - Click "Apply".
   - Render will now automatically:
     - Set up your Database (PostgreSQL).
     - Install all required Python packages.
     - Start your web server.

--------------------------------------------------------------------------------
STEP 3: Post-Deployment Settings (Important!)
--------------------------------------------------------------------------------
After your app shows a green "Live" status:
1. Go to your Render Dashboard.
2. Select your "Web Service" (e.g., "signal-forge").
3. Go to the "Environment" tab on the left.
4. Add the following variable for security:
   - Key: SESSION_SECRET
   - Value: (Put any random long string of letters and numbers here)
   - Click "Save Changes".
5. Add any other API keys (Stripe, OpenAI, etc.) here as well.

--------------------------------------------------------------------------------
TIPS FOR MAINTAINING THE SITE
--------------------------------------------------------------------------------
1. Automatic Updates: 
   Whenever you push a change to your GitHub repository, Render will see the
   added code and automatically update your live website. No manual work needed!

2. Free Tier "Sleep":
   On the free plan, if nobody visits your site for a few minutes, Render puts
   it to "sleep" to save power. When you visit the site again, it will take
   about 30-60 seconds to "wake up" and load the first time.

3. Monitoring:
   You can click the "Logs" tab in the Render dashboard to see exactly what 
   your code is doing or if there are any errors.

================================================================================
Your website is now live and professionally hosted!
